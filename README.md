# CSmarket.mn (demo)

Vite + React + TypeScript + Tailwind CSS project for the CSmarket CS2 skin marketplace demo.

## Run locally
```bash
npm install
npm run dev
```

## Deploy with Vercel
1. Upload this project to a GitHub repository.
2. Import that repository at https://vercel.com/new
3. Vercel detects Vite. Build command: `npm run build`; output directory: `dist`.
4. Deploy.

**Important:** This is a demo only. Listings/prices are sample data, not live BUFF163 data. Steam trading, deposits, and real payments are not enabled. Do not accept user funds through this demo.
